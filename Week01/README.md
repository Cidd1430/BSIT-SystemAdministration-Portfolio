# Reflection

This activity helped me understand the importance of creating a professional online presence through GitHub. Before this exercise, I only had a basic understanding of GitHub as a platform for storing code. By creating my GitHub profile, portfolio repository, and organizing weekly folders, I learned how developers and IT professionals document their work in a structured and accessible manner. I also gained experience using Markdown to create well-formatted documentation, which is an essential skill for writing technical reports, project documentation, and README files.

Another important lesson I learned was how Git and GitHub work together to manage files and track changes. I discovered that GitHub does not allow empty folders, so each folder must contain a file such as a `README.md`. This activity also introduced me to organizing projects in a way that makes them easy to maintain and update throughout the semester.

As a future System Administrator, I believe these tools will play a significant role in my career. GitHub will allow me to maintain configuration files, automation scripts, and documentation while keeping track of revisions. Markdown will help me create clear installation guides, troubleshooting procedures, and system documentation that can be shared with team members. Overall, this activity provided a strong foundation in version control, documentation, and professional portfolio development, which are valuable skills for managing IT systems and collaborating with other professionals.
